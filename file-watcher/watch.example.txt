# Danh sách thư mục cho file-watcher --config watch.txt
# 1 dòng = 1 thư mục. Dòng trống và dòng bắt đầu bằng # được bỏ qua.
# Đường dẫn tương đối được hiểu tương đối theo thư mục chứa file này.
# Copy file này thành watch.txt rồi sửa lại cho máy của bạn.
#
# Dòng bắt đầu bằng @ là cài đặt (không bắt buộc — thiếu thì dùng
# mặc định; file cũ chỉ có thư mục vẫn đọc bình thường):
#   @recursive true        đệ quy (true/false, mặc định true)
#   @debounce 200          gộp event dồn dập trong n mili-giây (mặc định 200)
#   @exts rs,md            chỉ hiện file có đuôi này (để trống là tất cả)
#   @ignore target,.tmp    bỏ qua đường dẫn chứa chuỗi này
#   @pin <đường-dẫn-file>  ghim 1 file để theo dõi riêng (tab Đã ghim);
#                          1 dòng @pin cho 1 file, đường dẫn có khoảng
#                          trắng vẫn được; ghim từ giao diện web cũng
#                          lưu thành dòng @pin ở đây
# Flag CLI gõ rõ (--ext, --ignore, --debounce-ms, --no-recursive)
# thắng cài đặt trong file này.
# Giao diện web (--serve) cũng lưu thay đổi vào file này.

# Ví dụ trên Windows:
# D:\code\project
# C:\Users\ten\Documents\ghi-chu

# Ví dụ trên Linux/macOS:
# /home/ten/code/project
# /home/ten/ghi-chu
