hairline-ui demo
Demo — every interaction works for real (drag sidebar, tint, fades)
Components

This page is a living showcase for the Hairline system: app shell, draggable sidebar (160–480px), stats, toolbar, tabs, log rows, path badge, toast, fades, tint, tinted hover. Source of truth: README.md in this folder.

Background color (tint)

Only the surrounding areas are tinted; the log keeps its original background.

Sample form

Hover preview pins the hover colour: with a tint set, it takes the tint's hue (same lightness shift as the stock hover). Hover any real button to compare.

Info

Drag the handle on the line between sidebar and content; double-click returns to 320px. Below 800px the sidebar stacks on top.
