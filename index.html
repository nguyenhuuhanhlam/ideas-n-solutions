Clipboard Tool

Tool tray thường trú trên Windows, viết bằng Rust, chỉ xử lý text thuần: mỗi lần copy, các module chạy tự động và ghi đè clipboard — phát hiện và chuẩn hoá link http/https, loại bỏ tham số fbclid nhưng giữ tất cả tham số còn lại. Không lưu clipboard xuống đĩa, tắt máy là hết; chỉnh module và tham số trong cửa sổ Settings Win32.

Ứng dụng Windows desktop — không có bản demo web

File Watcher

CLI viết bằng Rust, lắng nghe thay đổi file trong 1 hoặc nhiều thư mục: tạo, sửa, xóa, đổi tên đều ghi 1 dòng log có giờ, kèm user và PC ID của máy chạy để gom log nhiều máy vẫn phân biệt được. Dùng API thông báo của hệ điều hành nên không polling, lúc rảnh gần như không tốn CPU; debounce gộp các event dồn dập của 1 lần lưu file, lọc theo đuôi file, ghi thêm ra file log, chạy lệnh tùy chọn mỗi khi có thay đổi, hoặc in JSON để pipe sang tool khác. Cấu hình lưu dạng JSON (watch.json). Bật --serve để mở giao diện web local cấu hình thư mục và xem log theo thời gian thực — phong cách hairline grid (sáng/tối theo hệ thống), dải stat đếm event theo loại, sidebar 320px kéo co dãn và thu gọn được, cuộn không thanh trượt chỉ còn vệt mờ báo hiệu, chọn màu nền cho các vùng xung quanh (trừ log) kèm chỉnh độ đậm, log hiện badge thư mục cha (bấm để copy full path), nhóm event của 1 file thành dạng thu gọn, chia 3 tab Tất cả / Đã ghim / Đã xóa, ghim file để theo dõi riêng, và đường dẫn Windows hiện dạng thường (không còn tiền tố \\?\).

Ứng dụng dòng lệnh + giao diện web local — không có bản demo web
